🚀 Despliegue en Vercel (CrisBeBe)

Esta aplicación está diseñada como Single Page App (SPA) autocontenida. No necesita Node.js ni compilación en el servidor:

Pasos en tu terminal o GitHub: 
git init
git add index.html
git commit -m "feat: SecuraQ Finanzas Mobile PWA"
git branch -M main
git remote add origin https://github.com/CrisBeBe/securaq-finanzas.git
git push -u origin main

Luego ve a vercel.com, pulsa "Add New Project", selecciona el repositorio y presiona "Deploy". En 10 segundos tendrás tu URL pública HTTPS.
